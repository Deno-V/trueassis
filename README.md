# trueassis

**一个你只需要说话的私人秘书。**

它管你的工作、健康、体重、运动、读书、爱好、家务、财务 ——
然后在你瘫在椅子上不知道干什么的时候，告诉你：现在，做这件事，因为……

## 先看一个故事

周三晚上九点。小林打开电脑，脑子里一团麻。

有个数据合并的活儿好像快到期了，有个分支答应同事今天推，体检报告在抽屉里躺了两周没约复查，
上周说要开始跑步结果一次没跑，收藏夹里堆了十几篇"稍后读"，
周末想骑车去天津但还没查天气，还有个电影下周就下映了。

她做了什么？打开 B 站，刷到十一点半，然后带着更重的负罪感睡了。

**不是她懒。是"想清楚现在该做什么"这件事本身，就已经耗尽了她今天剩下的全部意志力。**

第二天她换了个做法。打开一个仓库，跟 AI 说了一句：

> 今天该干什么

```
╭─ 秘书简报  2026-08-06  周四
│  进行中 14 项 · 可执行 6 项
╰────────────────────────────────────

⚠️  逾期  (1)
  · 推 eval 分支给同事        逾期 1 天 · P1

📅 今天到期  (1)
  · 金融数据合并 —— 字段映射   今天到期 · P1 · 约 2h

▶️  建议现在做
  1. 推 eval 分支给同事
     已逾期 1 天，P1，约 30 分钟。你昨天答应了同事，这是欠着的承诺，先还掉。
  2. 金融数据合并 —— 字段映射
     今天到期，P1，约 2h。你画像里写「上午深度工作最佳」，但现在是晚上，
     建议只做「列出冲突字段」这一步，明早再收尾。

🌱 顺手推进
  · 约体检复查（停滞 14 天）—— 打个电话的事，别再拖了

💡 提醒
  · 「每周跑步 3 次」这周一次没做，还剩 3 天
  · 周末骑行还有 2 天，天气没查、装备没确认
  · 《XX》下周三下映，想看就得排进周末
```

她没有做完所有事。她做了第一件，30 分钟，还掉了那个承诺。
然后她给体检打了电话。然后她睡了，没有负罪感。

**这就是 trueassis 做的事：它不帮你做事，它帮你不必再纠结做什么。**

## 它不只是待办清单

待办清单只会存东西。存到 200 条，你就再也不敢打开了。

trueassis 是**秘书**。区别在这里：

| 你的处境 | 待办 App | trueassis |
|---|---|---|
| "我不知道现在该干什么" | 给你一个 200 条的列表 | 给你 3 条，**每条说清为什么是它** |
| "我只有 20 分钟，还很累" | 列表不变 | 只推 20 分钟内、不费脑的事 |
| "这事没截止日期" | 沉到列表底部，烂掉 | 14 天没动就捞出来问你：推进、降级、还是放弃 |
| "我不敢取消，怕是在逃避" | 让它永远躺着，成为负债 | **鼓励你放弃**，但要留一句理由 |
| "我这个月都干了啥？" | 不知道 | 自动生成日报周报月报，按领域汇总 |
| "希望它越来越懂我" | 它永远不懂 | 记住你的节律、偏好、雷区、当期重心 |

## 不只是工作 —— 四个真实场景

### 场景一：体重管理（把"我要减肥"变成会自动发生的事）

「我要减肥」是个愿望，不是任务，所以它永远不会发生。拆开就不一样了：

> 我想三个月内从 78 公斤降到 72，帮我安排

Agent 会建一个**项目**，然后拆出可执行的部分：

```
项目：减重到 72kg（ddl 11 月 5 日）
├─ 每周一早上称重并记录        ← 重复任务
├─ 每周跑步 3 次               ← 重复任务
├─ 每天记录三餐（简单记就行）   ← 重复任务
└─ 每月 1 号回顾体重趋势        ← 重复任务
```

之后你只需要随口说，怎么说都行：

> 今天称了，77.2

> 跑了 5 公里，配速 6 分半，膝盖有点酸

AI 会自己弄明白这是什么事：它去查你健康领域下有哪些任务、哪些是今天该做的、
以前记过什么，然后决定——把数据记进健康日志，顺手把今天那条「称重」标记完成。

**你不需要说"请把 77.2 记录到体重字段"。** 系统里根本没有"体重字段"，
它也不认识"公斤"这个词。是 AI 读懂了你的话，然后自己决定往哪写。

这一点很重要：正因为系统不认识任何特定领域，它才能处理**所有**领域。
你说"喝了 8 杯水""背了 50 个单词""练了 40 分钟琴""猫打完疫苗了"，
流程完全一样，不需要谁去给系统加一个"喝水功能"。

一个月后：

> 这个月体重怎么走的

```
📖 健康日志 · 2026-08

  08-04  77.8kg
  08-11  77.2kg
  08-18  76.9kg
  08-25  76.1kg   ← 一个月 -1.7kg，按这个速度能提前达成

  跑步 11 次（目标 12 次）· 累计 52km
  08-18 记录：膝盖有点酸 —— 出现 3 次了，建议换鞋或减量
```

**关键不是记录，是那句「出现 3 次了」。** 你自己不会发现，因为它散落在三周的日志里。
系统没有"统计膝盖酸痛"的功能——是 AI 把三周的原始记录读了一遍，然后看出来的。

### 场景二：运动与爱好（让计划真的发生，而不是躺在收藏夹）

> 周末想骑车去天津，帮我记一下，提前三天提醒我

Agent 建了个带时间点的 event，并设 3 天提前预警。周四早上简报里：

```
⏰ 3 天内 / 提醒窗口
  · 骑行 北京→天津    3 天后 · 约 8h

💡 提醒
  · 骑行还有 3 天，你还没确认：天气、装备、返程车票
```

骑完了：

> 骑完了，180 公里，骑了 9 个小时，最后 30 公里差点崩

这条会同时进健康日志和月报。**三个月后你想知道"我今年骑了多少公里"，一句话就能查到。**

### 场景三：健康（对抗"反正没事就不管"）

体检、复查、吃药、看牙——这类事的特点是**不紧急，但拖久了会很贵**。

> 每半年体检一次，每天晚上吃维D，牙齿每年洗两次

```
recurring: 体检          rule: every:180d
recurring: 吃维D         rule: daily
recurring: 洗牙          rule: monthly:1（一年两次，手动调）
```

这类任务的价值不在提醒，在**反腐烂机制**：
如果「约体检」这条躺了 14 天没动，它会被从列表深处捞出来，
出现在简报的「🌱 顺手推进」里，附一句"打个电话的事，别再拖了"。

### 场景四：读书与学习（区分"我要读"和"我想读"）

大多数人的读书清单失效，是因为把"我想读的 40 本书"和"我这周要读完的这本"混在一起了。
列表一长，你就不看了。

trueassis 强制区分：

> 我想读的书：DDIP、人类简史、置身事内、SICP

→ 全进**愿望池**（someday），不污染你的待办列表。

> 这个月我要读完 DDIP，每天晚上半小时

→ 变成真正的**任务 + 重复任务**，进日程。

每周复盘时，Agent 会问：「愿望池里有 12 本书 30 天没看过了，要不要提一本上来？」

## 第一次使用：三步，十分钟

### 第 0 步：你需要什么

- 一个 AI 编程工具：**Codex / CodeBuddy / Claude Code / Trae / Cursor** 任选其一
- Python 3.8+（macOS / Linux 自带，`python3 --version` 能出版本号就行）
- **不需要**安装任何依赖包。没有 `pip install`，没有账号，没有服务器。

### 第 1 步：拿到仓库，让 AI 认识它

```bash
git clone <这个仓库> trueassis
```

用你的 AI 工具打开这个文件夹，然后说：

> 读一下 AGENTS.md，然后帮我初始化

Agent 会读协议、跑 `init`、建好你的个人数据区。**从这一刻起你不需要再敲任何命令。**

### 第 2 步：填画像（最重要的一步，别跳过）

> 帮我填画像

Agent 会问你几个问题，大概这些：

- 你什么时段脑子最清楚？什么时段就是废的？
- 有什么事会让你炸？（比如"讨厌日程被塞满""不喜欢一天里频繁切换领域"）
- 这个季度你最想搞定的三件事是什么？
- 有什么固定安排？（周三健身、每周例会、通勤两小时）

**为什么这步最重要**：画像是它给建议的唯一依据。
画像空着，你得到的是"按优先级排序的列表"；画像填了，你得到的是
"你现在精力不行，而且下午你一向效率低，先做这个 20 分钟的小事把手热起来"。

### 第 3 步：把脑子里的东西全倒出来

不用整理，不用分类，想到什么说什么：

> 记一下：金融数据合并这周五要交，答应同事推 eval 分支，
> 体检报告要约复查，想开始跑步，周末想骑车去天津，
> 想读 DDIP 和人类简史，下个月房租要交，《XX》下周下映

Agent 会一次全收进来（一个原子操作，不会记一半），然后**只问关键的**：
哪些有硬截止日期？哪些其实只是想想（那就进愿望池，不占你的待办）？

十分钟后，你有了一个能用的秘书。

## 然后每天怎么用

### 早上 · 一句话

> 今天该干什么

得到：逾期什么、今天到期什么、建议先做哪 3 件、以及每件的理由。
挑一件，说"我开始做金融数据了"，它会标记进行中。

### 白天 · 随时

想到什么就说，成本要足够低，否则你就不会记：

> 记一下：下周要交房租

> 我刚跑了 5 公里，配速 6 分半

> 报销那个事不用办了，公司改政策了

> 骑行改到下周吧

碎片时间：

> 我只有 20 分钟，还挺累，能干点什么

它不会给你那个 3 小时的硬活。它给你能在 20 分钟里真正做完的事。

### 晚上 · 一句话

> 今天结束了

它会：生成到期的重复任务 → 生成日报（自动填好你今天完成了什么、记录了什么）
→ 归档已完成的 → 数据体检 → 然后问你三个问题：

```
1. 今天最有价值的一件事是什么？
2. 什么卡住了你？
3. 明天第一件事做什么？
```

**这三行是整个系统的燃料。** 它是画像的原料，是周报的素材，
也是三个月后你回头看"我那段时间到底在干什么"的唯一线索。
花一分钟，别跳过。

### 周日 · 十分钟

> 陪我做周复盘

它生成周报（按领域汇总你这周完成了什么、放弃了什么），
然后把停滞的事和没有截止日期的事列出来，逼你逐条做决定：

| 情况 | 你说 |
|---|---|
| 还要做 | "保留" |
| 早做完了忘了标 | "这个做完了" |
| 不做了 | "这个取消，因为……" |
| 该做但不是现在 | "推到下周" / "放愿望池" |

**不允许"先放着"。** "先放着"是清单腐烂的开始。

## 出错了怎么办

你不碰代码，所以 Agent 改错了你需要一个兜底。**每次写操作前系统都存了完整快照**：

> 错了，撤销

数据立刻回到那次操作之前。保留最近 30 次，包括文件移动和批量改动。

所以放心让 AI 操作。**改坏了，一句话就能回来。**

## 它怎么提醒你

有个必须讲清楚的事实：**AI 没有后台进程，它只在你跟它说话时才活着。**
所以"到点提醒"不可能由它自己发起。系统分三层：

| 层 | 干什么 | 需要配置吗 |
|---|---|---|
| **数据层** | 到期分区、提前预警、停滞检测、项目空转检测 | 不用，永远生效 |
| **会话层** | 你一开口，它先看数据主动汇报 | 不用，已写进协议 |
| **时钟层** | 到点弹通知戳你 | **需要装一次** |

第三层，敲一次命令（也是**唯一**需要你敲的，因为它要改系统定时任务）：

```bash
bash tools/install-reminders.sh
```

装完你会得到：早上 9 点如果有到期的事，桌面弹一条"今天有 3 项到期待办"；
晚上 9 点半提醒你写日报；周日晚上提醒你复盘。

**最好的组合**：让通知负责戳你（保证不漏），让 AI 负责想清楚（保证有用）。
通知弹出来 → 你去问一句"今天该干什么" → 得到带理由的建议。

## 你的数据在哪里，安全吗

**全在你自己的机器上。** 没有服务器，没有账号，没有云端。

```
trueassis/
├─ AGENTS.md  docs/  templates/  tools/     ← 框架，可以公开分享
└─ private/                                  ← 你的真实数据，永不进公共仓库
```

`private/` 被 `.gitignore` 隔离，框架仓库**永远**不会带上你的数据。
系统还会主动检查：一旦发现你的个人数据误入 git 索引，立刻报错并给出修复命令。

里面会有你的体重、健康记录、财务、人际关系。所以：
如果你想备份，给 `private/` 挂一个**独立的私有仓库**（见 [`docs/sync.md`](docs/sync.md)）。

每一条数据都是纯文本 Markdown。可以用任何编辑器打开，可以 git diff，
可以被任何 AI 直接读懂。**二十年后你还能打开它们。** 没有厂商锁定，没有导出格式问题。

## 为什么它能管所有领域

因为**它不认识任何领域**。

系统里没有"体重字段"、没有"跑步模块"、没有"读书进度条"。
工具只会做几件笨事：列出你有哪些未完成的事、它们在哪个文件、最近记了些什么。

理解"跑了 5 公里，膝盖有点酸"是什么意思、该记到哪、要不要标记完成 ——
**全部由 AI 完成**。它本来就懂人话，不需要谁教它"公里"是距离单位。

这个分工带来一个直接结果：

> 你说「喝了 8 杯水」「背了 50 个单词」「练了 40 分钟琴」「猫打完疫苗了」
> 「妈的生日礼物买好了」「那个需求评审推迟了」——
> **流程完全一样，不需要给系统加任何新功能。**

如果反过来做（在工具里写"体重、公里、页数"的解析规则），
那就永远补不完：今天加了体重，明天用户开始记血压、记咖啡因、记练琴时长……
每个新习惯都要改代码。**那种系统注定只能服务它作者想到的那几件事。**

## 常见疑问

**我需要学命令吗？**
不需要。所有命令都由 AI 执行。你从头到尾只说人话。
（唯一例外是安装提醒的那一行，因为它要改系统设置。）

**换电脑怎么办？**
`git clone` 框架 + `git clone` 你的私有数据仓库，两条命令恢复全部。

**我可以中途手动改文件吗？**
可以，它就是普通 Markdown。改完让 AI 跑一次体检就行。
**降级路径永远存在** —— 就算 Python 挂了，你还有一堆能读能改的文本文件。

**它会自动帮我改优先级、自动取消任务吗？**
不会。**系统只建议，决定权永远在你。** 这是有意的设计。

**AI 会不会把我的话理解错，记到不该记的地方？**
可能会。所以有两道保险：一是它在拿不准时会问你（尤其"标记完成"这类你看不见的操作）；
二是每次改动前都存了快照，你说一句"撤销"就回来了。

**为什么不做手机 App / 网页界面？**
因为入口是对话，不是又一个需要你打开的应用。
你已经有太多需要打开的应用了 —— 那正是问题的一部分。

**只有我一个人能用吗？**
框架是通用的。词表（领域、优先级）在 `config/config.yml` 里，随你改。
你的数据和别人的数据永远互不可见。
